**MultiView v1.3.2 — MultiView keeps itself up to date**

## What's new

- **Auto-update.** An installed copy checks GitHub at start-up and every 6 hours. A new release downloads in the background — the footer pill shows the percentage — and nothing is installed until you click that pill. One click installs and relaunches the app; MultiView never installs anything behind your back.
- **This one still installs by hand.** The updater lives inside 1.3.2, so this is the last manual download: run `MultiView-1.3.2-setup.exe` once, and every later version arrives on its own.
- **One Windows download instead of three.** Only `MultiView-1.3.2-setup.exe` is published; the single-file portable `.exe` and the `.zip` are gone. That installer installs for your user only, in one click, and needs no administrator rights.
- **Later updates stay small.** Each release now ships a blockmap next to the installer, so an update re-downloads only the bytes that changed instead of the whole 117 MB package. The first update after a manual install still takes the full package: the updater has no previous installer in its cache to compare against yet.
- **No version chain.** Skipped a few releases? The updater always goes straight from your version to the newest one — one download, one install, no intermediate steps.
- **Under the hood.** `electron-updater` replaces the hand-rolled GitHub release parsing and version comparison, and the update pill became a four-state readout: available, downloading, restart to apply, or failed with a link to the release page.

## Nouveautés

- **Mise à jour automatique.** Une copie installée interroge GitHub au démarrage puis toutes les 6 heures. La nouvelle version se télécharge en arrière-plan — la pastille du pied de page affiche le pourcentage — et rien n'est installé tant que tu ne cliques pas dessus. Un clic installe et relance l'application ; MultiView n'installe jamais rien dans ton dos.
- **Celle-ci s'installe encore à la main.** L'updater vit dans 1.3.2 : c'est donc le dernier téléchargement manuel. Lance une fois `MultiView-1.3.2-setup.exe`, et toutes les versions suivantes viendront toutes seules.
- **Un seul téléchargement Windows au lieu de trois.** Seule la pièce `MultiView-1.3.2-setup.exe` est publiée ; le `.exe` portable et le `.zip` disparaissent. Cet installeur installe pour ton utilisateur uniquement, en un clic, et ne demande pas de droits administrateur.
- **Les prochaines mises à jour restent petites.** Chaque release publie désormais un blockmap à côté de l'installeur : une mise à jour ne retélécharge que les octets qui ont changé, au lieu des 117 Mo du package complet. La première mise à jour après une installation manuelle prend encore le package entier : l'updater n'a pas encore d'installeur précédent en cache pour comparer.
- **Pas de chaîne de versions.** Tu as sauté plusieurs versions ? L'updater passe toujours directement de ta version à la plus récente : un téléchargement, une installation, aucun intermédiaire.
- **Sous le capot.** `electron-updater` remplace le parsing maison des releases GitHub et la comparaison de versions, et la pastille de mise à jour est devenue une jauge à quatre états : disponible, téléchargement, redémarrer pour appliquer, ou échec avec le lien vers la page de la version.
